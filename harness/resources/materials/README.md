# 공개 자료

회사 소개·채용 공고·문화와 확정 후보군 8명의 공개 이력서 PDF,
추출 텍스트, 지원동기, application.json을 포함합니다.
문서 버전 HR-PERSONALITY-2.0은 원본 작성 버전입니다.
모든 지원자는 서류·기술면접 통과 후 인성 면접을 진행합니다.

경량 하네스는 첫 실행에 [확정 후보군](../../candidate_pools.json)에서 P07을 먼저,
중상·중하·상 각 한 명을 무작위로 배정해 서로 다른 네 명만 진행합니다.
후보군에는 사용자와 확정한 ID만 저장하며 모델로 분포를 다시 추정하지 않습니다.
배정용 분류는 면접·최종 평가 입력에 포함하지 않습니다.
후보 private state·성격 정답·숨은 미래·다른 참가자 데이터는 없습니다.

[복사 출처와 해시](../../../developer/docs/import-manifest.json)를 참고하세요.
