# 분리 상태와 사용자 전달 상태

현재 Git 저장소나 Git worktree가 아니라 서로 독립된 폴더 복사본이다. 원본과 기존 리허설 폴더에서 Git 저장소가 아님을 확인했다.

| 폴더 | 용도와 변경 범위 |
| --- | --- |
| `founder-side-light` | 터미널 버전 구현 원본. 앞선 구현은 이곳에서 진행했다. 이번 리허설·사람다움 보완은 이곳의 제품 파일을 편집하지 않았다. |
| `founder-side-light-rehearsal-20260918-002202` | 원본 전체 복사본. 네 명 대화·대행 평가와 검증 기록을 보존한다. 최종 순위는 두 번의 시간 초과로 미완료다. |
| `founder-side-light-human-v2-20260918` | 후보 프롬프트 개선 실험. 새 가상환경을 사용하며 원본·리허설로 보완안을 반영하지 않았다. |

작업 시작 시 원본 130개 파일의 SHA를 기록했다. 마지막 대조에서 실행 코드·후보 자료·프롬프트의 변경은 없었다. 다만 AGENTS.md에 채팅·시연 출력 지침이 추가된 차이를 발견했다. 이 개선 작업에서 수행한 원본 편집은 아니며 변경 주체는 확인하지 못했다. 따라서 폴더 전체 무변경이라고 보고하지 않는다. 해당 변경을 덮어쓰거나 되돌리지 않았다.

원본과 human-v2에는 실제 면접용 terminal-light 세션을 만들지 않았다. 이번 검사에는 실제 Claude를 사용했지만 개발 질문이며 실제 사용자 평가가 아니다. 폴더와 가상환경은 분리됐고 Claude 로그인과 사용량은 같은 계정을 사용한다.

사용자 전달에는 작업 폴더 전체 대신 배포 ZIP을 사용한다. 기존 `dist/founder-side-light.zip`(Mac)과 `dist/light-ver-windows.zip`(Windows)은 실행 기록·가상환경·인증 파일 없이 필요한 파일이 포함됐음을 점검했다. 이 ZIP은 human-v2 보완 이전 버전이며 이번에 다시 만들지 않았다.

현재 정식 전달 완료 상태는 아니다. 최종 순위 생성 시간 초과와 AI 면접 마무리 안내 중복을 수정하고 전체 흐름을 다시 확인해야 한다. 후보의 사실 창작도 남아 있다. Windows 네이티브 실행은 미확인이다. 수정·검증 후 ZIP을 새로 만들고 사용자는 전체 압축 해제 후 Mac 실행.command 또는 Windows 실행.bat를 연다. 인터넷 연결·본인 Claude 로그인·인사이트 확인·각 후보 평가 입력은 필요하다.

후보 프롬프트 보완과 실제 검사 결과는 [검증 기록](human-v2-verification.md)에 있다.
