# 지원자 프롬프트 human-v2 검증

2026-09-18. 독립 복사본의 후보 프롬프트 **첫 보완안**에 대한 개발 검사다. 아래 해시의
8회 결과를 보존하며, 이후 추가 보완안의 결과와 합쳐 성공률을 계산하지 않는다. 기존 네 명 리허설의
면접·평가·순위를 수정하거나 다시 실행하지 않는다. 실제 사용자 면접 완료로 집계하지 않는다.

## 검사 범위

`scripts/verify_candidate_human_v2.py`로 P08·P06 각각 네 질문을 순서대로 전달한다.
두 후보는 최대 두 호출까지 병렬로 실행하고, 같은 후보의 다음 질문은 직전 실제 응답 뒤에
전달한다. 자동 재시도 없이 총 여덟 호출 이내로 제한한다. 기존 `candidate_context`와
`Claude('sonnet')` 실행기를 사용하며, 프롬프트·자료 해시가 달라지면 진행하지 않는다.

| 후보 | 질문 흐름 | 검토할 점 |
| --- | --- | --- |
| P08 | 넓은 보고 방식 → 첨부 누락 당시 전달 → 인계 후 연락 여부 → 재량 포기 압박 | 첫 답의 길이, 알려진 사실 보존, 미확인과 미행동의 구분, 과도한 자기비판과 성향 변경 |
| P06 | 넓은 개선 경험 → 외부 검토 운영 → 미완료를 완료로 표시하자는 실제 대화 여부 → 개선 여건 없는 역할 | 구체성을 요청하면 실제 사실로 답하는지, 원칙을 설명하려고 새 사건을 만드는지, 명시한 우선순위 유지 |

발화와 실행 메타데이터는 `.runtime/verification/candidate-human-v2/<run-id>/`에 저장한다.
후보 설정 원문, 입력 컨텍스트, 다른 후보 자료, 구간·미래 정보, 인증값과 원시 CLI 출력은
저장하지 않는다. 원자료와의 대조는 허용된 해당 후보의 과거·현재 자료와 공개 지원서만 사용한다.

## 해석의 한계

두 후보의 짧은 후속 질문 검사다. 이전 긴 리허설과 질문 수·대화 맥락이 같지 않고 모델
응답에도 변동이 있으므로 엄밀한 전후 비교나 전체 후보 품질 보증으로 해석하지 않는다.
긴 대화에서의 사실 누적, 마무리 반복, 네 명의 실제 사용자 평가 흐름은 이번 범위 밖이다.
