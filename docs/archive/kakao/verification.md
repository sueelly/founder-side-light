- `python -m pytest -q`: **99개 통과**. `python -m harness doctor`: 정적 확인 통과.
- 카카오 CLI와 Windows 창 제어 구현을 삭제했습니다. pywin32 의존성과 Homebrew·SQLCipher·Swift
  설치 경로를 제거하고, 이 워크트리의 이전 CLI 실행 파일·다운로드 소스·빌드 자료도 제거했습니다.

  첫 연결은 실제 화면 관찰을 등록하기 전에는 완료되지 않습니다.
- 전송 1회 예약, 새 본인 말풍선 확인, 불확실 전송의 재전송 방지, 명시적 복구,
  반복 본문의 서로 다른 관찰 ID, 원문·대화방 불일치 차단을 검증했습니다.
- 시작 말풍선의 확인이 늦거나 재시작해도 마감이 연장되지 않는 것, 마감·새 답변·후보 변경으로
  오래된 전송 요청이 취소되는 것, 늦은 발언이 평가 원문에서 제외되는 것을 검증했습니다.
- 기존 공용 대화방 세션을 전환할 때 배정·시계·원문·기준 사본을 보존하는 것을 확인했습니다.
- 새 화면 전달 방식으로 **합성 면접 4회 → 필수 사용자 평가 → 최종 순위·payload 생성**까지
  실행했습니다. 실제 사용자 평가를 대신 작성하거나 외부로 전송한 검사가 아닙니다.
- 배포 검사에는 새 연결 코드·운영 문서 포함, 삭제한 카카오 구현·pywin32·개인 런타임 제외를 포함합니다.

이 변경의 검증은 **합성 화면 관찰·모델 출력과 로컬 정적 검사**입니다.
실제 Claude Desktop computer use의 카카오 읽기·발송·수신, Windows 실기, 실제 모델 생성,
참가자 인증 제출·최종 API 접수는 실행하지 않았습니다. 아래 구버전 연결 확인 기록이
