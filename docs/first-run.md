# 첫 실행과 재개

[setup.md](../setup.md)의 시작 파일을 실행하세요. OS·연결 설정 입력 없이 의존성과 본인 Claude 인증을
확인합니다. 준비된 환경에서는 `insights.md`를 작성하고 `시작`을 입력하면 됩니다.

첫 면접은 사람 면접관, 다음 세 면접은 Claude 면접관이며 지원자는 모두 Claude입니다.
매 면접 후 사용자 평가와 인사이트 변경 여부를 확인합니다. 최종 순위는 로컬에만 저장합니다.

Mac은 uv와 Python 3.12, Windows는 기존 Python 3.11 이상 또는 WinGet의 공식 Python 3.13을 사용합니다.
패키지는 프로젝트의 `.venv`에 설치됩니다. 시작 파일은 테스트와 doctor를 수행하며 실패하면 면접을 열지 않습니다.
설치 및 검사 로그는 `.bootstrap/`에 있습니다. 자세한 진행 명령은 [README](../README.md)를 참고하세요.

같은 폴더의 시작 파일을 다시 실행하면 `.runtime/terminal-light`에서 이어집니다.
후보 배정·기준 사본·시작 및 마감 시각은 유지합니다. 모델 생성이 중단된 차례는 `/retry`로 재시도합니다.
이미 마감이 지났으면 이전 질문을 생성하지 않고 종료부터 기록합니다.
기존 `.runtime/light`의 카카오 세션은 자동 변환하지 않으며 파일을 보존합니다.
